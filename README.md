# Popper

## Description
An endless arcade bubble-popping game developed for iOS. Bubbles continuously spawn at the bottom of the screen and float upwards. The player's goal is to tap and pop as many bubbles as possible before they escape past the top edge. The gameplay is endless and continues until 3 bubbles reach the top unpopped, resulting in a Game Over.

## Tech Stack
- Swift: Primary programming language

- Xcode: IDE and build environment for iOS

- SwiftUI: Declarative UI framework


## Key Features
- 3-Screen Structure: Features a Main Menu, an instructions screen ("How to Play"), and the main Gameplay screen.

- Endless Gameplay & Scoring: Earn 1 point per popped bubble. The game continues until 3 bubbles escape to the top.

- Dynamic Difficulty System:
  - Very Easy (0–9 points): Bubbles move slowly and are very easy to hit.
  - Challenging (10–29 points): Bubbles spawn faster and float at an increased speed.
  - Very Hard (30+ points): High-speed spawning and rapid movement designed to test player reflexes.
